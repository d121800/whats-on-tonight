# 畫面流程與狀態機

程式對應：`frontend/src/stores/game.js` 的 `scene` 欄位與 `SCENES` 陣列；
`frontend/src/views/GameView.vue` 的 `sceneMap` 依 scene 切換場景元件。
新增或改動狀態時，這份文件、`SCENES`、`sceneMap` 三處要一起改。

## 頁面層（vue-router）

| 路由 | 元件 | 內容 |
|---|---|---|
| `/` | TitleView | 標題、Start、繼續、Setting；下方關於／成就／生日圖示鈕 |
| `/game` | GameView | 遊戲本體，依 store.scene 切換場景 |
| `/settings` | SettingsView | 等級（普通／瓦哈，下一局生效）、下載紀錄、清除存檔 |
| `/about` | AboutView | placeholder |
| `/achievements` | AchievementsView | 草圖 7 四個成就 + 進度條（解鎖未實作） |
| `/birthday` | BirthdayView | 暫定為生日留言牆，待接 API |

## 遊戲層狀態機

```
tutorial        阿邁小精靈教學，三段（草圖 2）：
  intro         訊息畫面，阿邁自我介紹
  room          房間裡阿邁站在桌邊講解，底部對話框
  focus         暗幕聚焦螢幕，點螢幕 → streamSetup
  Skip（橘色，右下角）→ streamSetup

room            日常房間（草圖 2）：右上資訊面板（第幾日、日期、時間、直播預告、體力），
                桌上螢幕可點，底部圖示列：對話泡泡（功能待定）、貓、手機（紅點）、睡覺 [暫定]、齒輪
  點螢幕        → streamSetup（第七天改為 → birthdayStream）
  吸貓          時間 +30 分、體力 +10~30；當日第三次被拒且不耗時
  手機          時間 +30 分 → phone（推進後若被接管則不進）
  睡覺          → sleep（入口放底部圖示列，hannah 2026-10-29 定案）
  齒輪          → /settings
  出門          沒有獨立按鈕，只能從 phone 的 Line 約朋友
  任何推進時間後：
    體力 ≤ 0    → collapse
    時間 ≥ 03:00 → sleep（強制，[暫定] 不可拒絕）

phone           社群（Bear）貼文列表 / Line 列表 → 聊天室
  約出來        → meetup
  關閉          → room

meetup          雙人見面（草圖 5）：朋友與阿萬並肩 + 一句話
  一起出門走走  時間 +1~3 小時、體力 +25~40（依時數插值，[暫定]）；推進後可能被 sleep／collapse 接管
  回家          → room

streamSetup     開播準備（草圖 13 左）：名稱、type 六種圖示、人（🚫 不找人＋五位朋友）、預計 1~4 hr
  開始          → streamLive
  取消          → room

streamLive      實際 60 秒（草圖 14）：內容區（右上 Live 紅點 + 壓力圓徽章）、標題列（倒數）、
                Day／日期／人數；右欄聊天室在上、朋友頭像 + 控場／炒熱／衛教直向按鈕在下；
                手機直式順序：內容、標題、資訊、指令、聊天室
  QTE 疊層      壓力 ≥ 門檻或每秒隨機觸發（開播前幾秒不觸發，每場有上限）
                標記來回跑，點螢幕／空白鍵停在隨機目標區內 = 煞車成功，否則失控
                QTE 進行中倒數暫停，指令按鈕停用；結果改壓力，不切換 scene
  倒數結束      → streamResult

streamResult    草圖 13 右：標題框、short／訂閱人／人氣／壓力／體力、評價氣泡 + 阿萬頭像
  End           時間 + 預計時數，再走 room 的推進檢查 → room / collapse / sleep

sleep           依就寢時間查表決定隔天體力
  睡覺          → dayTransition（day +1，上班 -20，19:00）
  再撐一下      → room（僅非強制時）

collapse        累倒文字敘述
  繼續          → dayTransition（day +2，不上班，體力 [暫定] 60%）

dayTransition   顯示 Day N 與日期；第七天補滿體力
  回家          → room

birthdayStream  [暫定] 純演出倒數 15 秒
  結束          → streamResult → ending

ending          結算 → CG → 填 name / birth msg（可略過）→ 製作名單 → 回首頁
```

## 時間模型

- `clock` 為「活動日 00:00 起算的分鐘數」，可超過 1440。跨午夜仍屬同一活動日，
  符合手稿「累倒跳日依活動所屬日判定」。
- `day` 為活動日（1～7），日曆日期由 `fmtDate(day)` 推算。
- 每天從 19:00（1140 分）開始；`forceSleepTime` 為 27:00（1620 分）即隔日 03:00。

## 已知流程缺口（待定案）

- 第六天累倒理論上跳到第八天，目前強制停在第七天並補滿體力，缺轉場演出。
- 生日直播是否可操作指令，目前純演出。
- 直播關卡（手稿第 17 張）只做了煞車 QTE 一種，其餘未實作。
- 「約出來」見面畫面只有一張圖與一句話，事件內容待文本。
- 直播類型圖示對應（刀＝動作？骷髏＝恐怖？團康沒畫）待確認。
- 成就四個的解鎖條件待定。
- 底部對話泡泡圖示功能未註明，先放著不接功能。
- 音符節奏關卡不做（hannah 2026-10-29）；問答關卡玩法待描述。
